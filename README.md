# 🔐 Apuntes de Ciberseguridad

Repositorio personal donde recopilo mis apuntes, resúmenes, guías y recursos mientras aprendo ciberseguridad. Está pensado como material de estudio y consulta rápida, y está en constante evolución.

> ⚠️ **Aviso:** Todo el contenido tiene fines **exclusivamente educativos**. Practica solo en entornos que controles o donde tengas autorización explícita (laboratorios propios, CTFs, plataformas de práctica).

---

## 📚 Contenido

| Carpeta | Descripción |
|---|---|
| [`fundamentos/`](./fundamentos) | Conceptos base: tríada CIA, criptografía, modelos de amenazas, tipos de ataque |
| [`redes/`](./redes) | Modelo OSI, TCP/IP, protocolos, Wireshark, nmap |
| [`sistemas/`](./sistemas) | Linux, Windows, línea de comandos, hardening |
| [`web/`](./web) | OWASP Top 10, inyecciones, XSS, CSRF, Burp Suite |
| [`pentesting/`](./pentesting) | Metodología, reconocimiento, explotación, post-explotación |
| [`defensa/`](./defensa) | Blue team, SIEM, logs, respuesta a incidentes, forense |
| [`criptografia/`](./criptografia) | Cifrado simétrico/asimétrico, hashing, PKI |
| [`ctf/`](./ctf) | Writeups de CTFs y máquinas (HackTheBox, TryHackMe, etc.) |
| [`herramientas/`](./herramientas) | Cheatsheets de herramientas y comandos útiles |
| [`recursos/`](./recursos) | Libros, cursos, canales, blogs y enlaces de interés |

> Ajusta esta tabla a la estructura real del repo conforme vaya creciendo.

## 📝 Convenciones

- Los apuntes están escritos en **Markdown**.
- Un archivo por tema, con nombres en minúsculas y guiones (`ataques-xss.md`).
- Cada nota incluye, cuando aplica: concepto, ejemplos, comandos y referencias.
- Las imágenes van en una carpeta `img/` dentro de cada sección.
