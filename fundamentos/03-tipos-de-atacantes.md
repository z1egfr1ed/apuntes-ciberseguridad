# Tipos de atacantes

## Por motivación y ética

| Tipo | Descripción |
|---|---|
| **White hat** | Hackers éticos: buscan fallos con autorización para corregirlos (pentesters, investigadores) |
| **Black hat** | Atacan sin autorización con fines maliciosos o lucrativos |
| **Grey hat** | Actúan sin permiso pero sin intención maliciosa clara; a menudo reportan lo que encuentran |
| **Script kiddie** | Usan herramientas hechas por otros sin entender del todo cómo funcionan |
| **Hacktivista** | Motivación política o ideológica |
| **Cibercriminal** | Motivación económica: ransomware, fraude, venta de datos |
| **Actor estatal (APT)** | Grupos respaldados por estados: espionaje, sabotaje; ataques persistentes y sofisticados |
| **Insider** | Empleado o colaborador con acceso legítimo que abusa de él (malicioso o negligente) |
| **Competidor** | Espionaje industrial |

## Por nivel de sofisticación

- **Oportunistas:** lanzan ataques masivos y automatizados, buscan objetivos fáciles.
- **Dirigidos:** eligen un objetivo concreto y preparan el ataque.
- **APT (Advanced Persistent Threat):** campañas largas, sigilosas y con muchos recursos.

## Modelo "Equipos"

- **Red Team:** simula atacantes reales (ofensivo).
- **Blue Team:** defiende, monitoriza y responde (defensivo).
- **Purple Team:** colaboración entre ambos para mejorar la defensa.
- **White Team:** árbitros y coordinadores de ejercicios.
