# Marcos y estándares

## Marcos de gestión y gobierno

| Marco / Estándar | Descripción |
|---|---|
| **ISO/IEC 27001** | Estándar internacional para un Sistema de Gestión de Seguridad de la Información (SGSI); certificable |
| **ISO/IEC 27002** | Guía de buenas prácticas y controles de seguridad |
| **NIST Cybersecurity Framework (CSF)** | Marco con funciones: Gobernar, Identificar, Proteger, Detectar, Responder, Recuperar |
| **NIST SP 800-53** | Catálogo detallado de controles de seguridad |
| **CIS Controls** | Lista priorizada de acciones defensivas concretas |
| **COBIT** | Gobierno y gestión de TI |

## Conocimiento sobre amenazas y ataques

| Recurso | Para qué sirve |
|---|---|
| **MITRE ATT&CK** | Matriz de tácticas y técnicas de adversarios reales |
| **MITRE CVE / NVD** | Catálogo y base de datos de vulnerabilidades |
| **CWE** | Catálogo de tipos de debilidades de software |
| **CAPEC** | Patrones de ataque comunes |
| **Cyber Kill Chain** | Modelo de fases de un ataque |
| **Diamond Model** | Análisis de intrusiones (adversario, infraestructura, capacidad, víctima) |

## Seguridad de aplicaciones

- **OWASP Top 10:** los riesgos más críticos en aplicaciones web.
- **OWASP ASVS:** estándar de verificación de seguridad de aplicaciones.
- **OWASP Testing Guide (WSTG):** guía de pruebas de seguridad web.
- **OWASP SAMM:** modelo de madurez del software seguro.

## Pruebas de penetración

- **PTES:** Penetration Testing Execution Standard.
- **OSSTMM:** metodología abierta de testeo de seguridad.
- **NIST SP 800-115:** guía técnica de pruebas de seguridad.

## Cumplimiento normativo (visión general)

- **GDPR / RGPD:** protección de datos personales en la UE.
- **PCI DSS:** seguridad de datos de tarjetas de pago.
- **HIPAA:** datos de salud en EE. UU.
- **SOC 2:** informes sobre controles de proveedores de servicios.
- Revisar además la **normativa local** de protección de datos y delitos informáticos de tu país.

## Respuesta a incidentes

Ciclo NIST (SP 800-61):

1. Preparación
2. Detección y análisis
3. Contención, erradicación y recuperación
4. Actividad posterior al incidente (lecciones aprendidas)
