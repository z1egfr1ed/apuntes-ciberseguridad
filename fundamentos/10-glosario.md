# Glosario

| Término | Significado |
|---|---|
| **APT** | Advanced Persistent Threat: amenaza avanzada y persistente |
| **Backdoor** | Puerta trasera para acceso no autorizado |
| **Blue Team** | Equipo defensivo |
| **Botnet** | Red de dispositivos infectados controlados remotamente |
| **Brute force** | Fuerza bruta: probar combinaciones hasta acertar |
| **C2 / C&C** | Command and Control: servidor que controla sistemas comprometidos |
| **CIA** | Confidencialidad, Integridad y Disponibilidad |
| **CVE** | Common Vulnerabilities and Exposures: identificador de vulnerabilidad |
| **CVSS** | Sistema de puntuación de severidad de vulnerabilidades |
| **CTF** | Capture The Flag: competencias de seguridad |
| **DDoS** | Denegación de servicio distribuida |
| **DFIR** | Digital Forensics and Incident Response |
| **DLP** | Data Loss Prevention: prevención de fuga de datos |
| **EDR** | Endpoint Detection and Response |
| **Exploit** | Código que aprovecha una vulnerabilidad |
| **Firewall** | Sistema que filtra el tráfico de red |
| **Hash** | Resumen de longitud fija obtenido de unos datos; no reversible |
| **Honeypot** | Señuelo para atraer y estudiar atacantes |
| **IAM** | Identity and Access Management |
| **IDS / IPS** | Sistema de detección / prevención de intrusiones |
| **IoC** | Indicador de compromiso |
| **MFA / 2FA** | Autenticación multifactor / de dos factores |
| **MitM** | Man-in-the-Middle |
| **OSINT** | Inteligencia de fuentes abiertas |
| **Payload** | Carga útil de un exploit o malware |
| **Pentest** | Prueba de penetración |
| **PKI** | Infraestructura de clave pública |
| **Ransomware** | Malware que cifra datos y exige rescate |
| **Red Team** | Equipo ofensivo que simula atacantes |
| **RCE** | Remote Code Execution: ejecución remota de código |
| **Salt** | Dato aleatorio añadido a una contraseña antes de aplicar el hash |
| **SIEM** | Security Information and Event Management |
| **SOC** | Security Operations Center |
| **SOAR** | Security Orchestration, Automation and Response |
| **TTP** | Tácticas, técnicas y procedimientos |
| **VPN** | Red privada virtual |
| **Vulnerabilidad** | Debilidad explotable en un sistema |
| **WAF** | Web Application Firewall |
| **Zero-day** | Vulnerabilidad sin parche conocida por el atacante |
| **Zero Trust** | Modelo que no confía en nada por defecto |
